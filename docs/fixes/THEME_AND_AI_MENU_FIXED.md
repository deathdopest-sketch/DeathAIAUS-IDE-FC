## 🎯 **How to Use Theme Selector**

### **Method 1: Double-Click** ⭐ **FASTEST!**
```
1. Menu → View → Themes...
2. Select a theme from list
3. Double-click it
4. Done! Theme applied!
```

### **Method 2: Apply Button**
```
1. Menu → View → Themes...
2. Click a theme
3. Click green "✓ Apply Theme" button
4. Done!
```
