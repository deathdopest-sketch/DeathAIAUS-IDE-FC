## 🐛 Troubleshooting

### IDE Won't Launch
```bash
# Check dependencies
pip install -r requirements.txt

# Run from correct directory
cd C:\Users\Death\Desktop\DeathAIAUS-IDE-FC
python deathaius_ide_fc.py
```

### Shortcuts Not Working
- Click on the editor first
- Make sure no dialog is open
- Check if Ctrl key is working

### AI Chat Not Responding
- Verify LM Studio is running (localhost:1234)
- Check that a model is loaded
- Look at terminal for error messages

### Syntax Highlighting Missing
- Save the file first (.py or .js extension)
- Close and reopen the tab
- Check file extension is correct
