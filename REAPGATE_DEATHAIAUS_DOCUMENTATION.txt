3. REAPGATE BACKEND
================================================================================

REAPGATE is a custom Go-based inference server designed specifically for
DeathAIAUS IDE FC. It replaces LM Studio with a purpose-built solution.

TECHNICAL SPECIFICATIONS:
- Language: Go 1.21
- Web Framework: Gin-Gonic
- AI Backend: go-llama.cpp (Go bindings for llama.cpp)
- Architecture: RESTful API server
- Port: 7777
- Model Format: GGUF (GGML Universal Format)

API ENDPOINTS:
- GET  /health                    - Health check
- GET  /v1/models                 - List available models
- POST /v1/chat/completions       - Chat completions
- POST /v1/models/load            - Load specific model
- POST /v1/models/unload          - Unload current model
- GET  /v1/models/current         - Get currently loaded model
- GET  /v1/models/status          - Get model loading status

FEATURES:
- Automatic model detection from Death's Pantheon directory
- On-demand model loading and unloading
- Memory management with configurable model limits
- GPU acceleration support (CUDA/OpenCL)
- Real-time model switching
- Comprehensive error handling and logging
- Branded startup with ASCII art

CONFIGURATION:
- Model Directory: G:\My Drive\DeathAIAUS_PANTHEON
- Max Models in Memory: 2 (configurable)
- GPU Layers: 0 (CPU only, configurable)
- Context Size: 2048 tokens
- Server Timeout: 30 seconds

BUILD REQUIREMENTS:
- Go 1.21 or later
- MinGW-w64 (for Windows C++ compilation)
- CGO enabled for C++ bindings
- Required DLLs: libwinpthread-1.dll, libstdc++-6.dll, libgcc_s_seh-1.dll

   Copy from C:\mingw64\mingw64\bin to ReapGate\:

   - Restart ReapGate: AI > Restart ReapGate
   - Check port 7777: netstat -an | findstr 7777

   - Workaround: None available until architecture support added

4. "Build failed"
   - Ensure Go 1.21+ is installed
   - Add MinGW to PATH
   - Enable CGO: $env:CGO_ENABLED=1
