## 9. TIPS & TRICKS

### **Tip 1: Preview Before Applying**
When AI suggests changes, you'll see a preview dialog.
- Green = additions
- Red = deletions
- Press Enter to approve, Esc to reject

### **Tip 2: Always Have Backups**
IDE auto-creates backups in `ai_backups/` folder.
- Click "💾 Backups" to browse
- Restore any version with one click
- Never lose work!

### **Tip 3: Track Model Performance**
After using AI for a while:
- Click "📊 Model Stats"
- See success rates
- Switch to best-performing model
- Stop wasting time on bad models!

### **Tip 4: Use Task Planner for Big Projects**
Don't let AI "do everything at once":
- Press `Ctrl+Shift+P`
- Get step-by-step plan
- Approve each step
- Stay in control!

### **Tip 5: Check Session Memory**
If AI "forgets" something:
- Press `Ctrl+Shift+M`
- See what AI remembers
- Export/clear if needed

## 10. TROUBLESHOOTING

### **Problem: No AI models detected**
**Solution:**
1. Check LM Studio is running (http://localhost:1234)
2. OR put .gguf files in Google Drive (G:\My Drive)
3. Restart IDE

### **Problem: AI not responding**
**Solution:**
1. Check model is selected (bottom right)
2. Try different model
3. Check `📊 Model Stats` for working models

### **Problem: Desktop shortcut not working**
**Solution:**
1. Run `CREATE_DESKTOP_SHORTCUT.bat`
2. OR double-click `launch.bat`
3. OR run `python deathaius_ide_fc.py`

### **Problem: Errors in terminal**
**Solution:**
1. Check Python is installed
2. Run `pip install -r requirements.txt`
3. Check terminal for specific error
4. Use `🔧 Fix Errors` button
